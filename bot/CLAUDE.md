# CLAUDE.md — Polypox Terminal

Guidance untuk Claude Code (atau agent lain) saat kerja di folder `bot/`.

> **TL;DR:** Bot trading otomatis BTC up/down 5-menit di Polymarket. Single FastAPI backend + React dashboard. Real-time pakai WebSocket. Sudah hardened untuk real mode dengan pre-flight validator 17 checks.

---

## Scope

**BTC-only, every 5 minutes.** Bot trade Polymarket `btc-updown-5m-{window_ts}` markets. No multi-asset (next phase: trade Binance spot), no soccer scanner, no SL/TP per-trade (Polymarket tidak punya native SL/TP — relies on auto-claim at window resolve).

**Modal sources:**
- **SIM** — fully simulated, no real CLOB calls (testing UI/logic)
- **DRY_RUN** — real market data + real orderbook, synthetic fill (no real orders submitted)
- **REAL** — real CLOB orders di Polymarket, real USDC at risk

## Backend Architecture (`backend/main.py`)

Single FastAPI file (~2000 LOC). 7 async loops jalan bersamaan, semua state di-share via global `S = BotState()`.

### Async Loops

1. **`btc5m_loop()`** — inti bot, poll setiap **2 detik**:
   - Fetch BTC price (Binance → CoinGecko → CryptoCompare fallback)
   - Tiap 55s: fetch 120 klines 1m + market data Gamma
   - Compute 7-indicator signal → confidence, score, direction
   - Cek circuit breakers (daily SL/TP, streak, hours, price, sentiment)
   - FIRE entry kalau: `in_entry_zone (T-10s→T-5s)` OR `spike_detected (score jump ≥1.5)` OR `hard_deadline (T-5s)`
   - Broadcast btc5m state via WS

2. **`orderbook_loop()`** — public CLOB poll setiap 2 detik:
   - Fetch YES + NO book parallel dari `clob.polymarket.com/book?token_id=...`
   - Hitung mid_yes, mid_no, comb
   - Broadcast `orderbook` WS msg

3. **`scanner_loop()`** — housekeeping, default 12s:
   - daily_reset (kalau ganti hari)
   - Broadcast stats + gas info

4. **`balance_refresh_loop()`** — setiap 5 menit:
   - `fetch_balance_pol()` Polygon RPC (5 fallback)
   - Real mode: `fetch_balance_usdc()` via CLOB `get_balance_allowance(signature_type=2)`
   - Drift detection: kalau > $5 saat open pos, log warning (jangan overwrite)

5. **`resolver_loop()`** — SIM + DRY_RUN: setiap 5s, random resolve posisi yang expired

6. **`redeem_winning_positions()`** — REAL only: adaptive polling 15s/60s/300s:
   - Cek posisi yang elapsed ≥ resolve_sec * 90%
   - `GET /markets/{conditionId}` cek closed/resolved
   - Kalau menang: `client.redeem_positions(condition_id=...)` → auto-claim USDC
   - Retry max 3x → `REDEEM_CRITICAL` log untuk manual review

7. **`reconcile_real_positions()`** — REAL only: startup-once, setelah 8s grace
   - `client.get_orders()` → compare state vs CLOB
   - Flag `RECONCILE_MISSING_CLOB` / `RECONCILE_ORPHAN_CLOB` (no auto-mutate)

### Signal Engine (`btc5m_analyze`)

7 indikator weighted (max ±14 score):

| # | Indikator | Max | Source |
|---|---|---|---|
| 1 | Window Delta | ±7 | `(price - win_open) / win_open` |
| 2 | Micro Momentum | ±2 | last 2 candle direction |
| 3 | Acceleration | ±1.5 | momentum delta |
| 4 | EMA 9/21 | ±1 | EMA crossover |
| 5 | RSI 14 | ±2 | overbought/oversold |
| 6 | Volume Surge | ±1 | recent 3 vs prior 3 |
| 7 | Tick Trend | ±2 | 60%+ ticks same direction |

`confidence = min(|score|/7, 1.0)`. Direction "" if confidence < 0.25.

### Compound Sizing

```python
compound_bet(equity) = max(1.0, floor(equity * 0.20 * 10) / 10)  # 20% flat, $0.10 step, min $1, max $50
```

| Equity | Bet | % |
|---|---|---|
| $7 | $1.30 | 19.5% |
| $10 | $2.00 | 20% |
| $25 | $5.00 | 20% |
| $50 | $10.00 | 20% |
| $100 | $20.00 | 20% |
| $250 | $50.00 | 20% (max) |
| $500 | $50.00 | 10% (capped) |

### Strategy Config (runtime-mutable via `POST /api/config`)

15 fields, persisted ke `state_{BOT_ID}.json`:
- **Position:** `bet_size`, `use_compound`
- **Circuit breakers:** `max_loss_strike`, `max_win_strike`, `daily_tp_usd`, `daily_sl_usd`
- **Entry triggers:** `conf_threshold` (default 0.25), `trigger_range`
- **Price window:** `price_min_cents`, `price_max_cents`
- **Sentiment:** `sentiment_lower`, `sentiment_upper`
- **Trading hours:** `trading_start`, `trading_end`, `trading_active`

### Gas Engine

- `gas_usable_pol = pol_left * 0.50` (50% reserve)
- `gas_cost_per_order = 0.02 USD / 0.40 USD/POL = 0.05 POL`
- Auto-pause kalau `orders_left ≤ 2`
- Resume via `POST /api/gas/resume`

### Circuit Breakers

Dicek di `btc5m_loop` sebelum entry via `check_circuit_breakers(cfg, b5)`:

| Breaker | Effect |
|---|---|
| `daily_sl_usd` hit | Auto-pause bot |
| `daily_tp_usd` hit | Auto-pause bot |
| `max_loss_strike` hit | Auto-pause bot |
| `max_win_strike` hit | Auto-pause bot |
| Out of trading hours | Skip entry (no pause) |
| Price out of range | Skip entry |
| Sentiment out of range | Skip entry |

## Critical Details to Remember

### 1. CLOB ID Format
- **Gamma `id`** = integer like `2311197` (internal Gamma DB ID)
- **CLOB `conditionId`** = hex like `0xd9fc6f45fd73f0a6cebb4d46334807d8492c3f16fec8a4589bb14cf350fca9bd`
- **CLOB endpoints `/markets/{...}` dan `redeem_positions()` butuh `conditionId`, BUKAN Gamma id**
- Position dict stores both: `pos.market_id` (Gamma) + `pos.condition_id` (CLOB hex)

### 2. ERC-1155 Token IDs (clobTokenIds)
- Per outcome (UP / DOWN), masing-masing punya `clob_token_id`
- Required oleh `OrderArgs(token_id=...)` saat place order
- Stored di `pos.clob_token_id`

### 3. Polymarket Proxy Wallet
- USDC tidak di EOA, tapi di **proxy contract** (signature_type=2)
- `client.get_balance_allowance(BalanceAllowanceParams(asset_type=COLLATERAL, signature_type=2))`
- POL gas tetap di EOA (`acct.address`)

### 4. Timezone
- Backend: UTC (`opened_at` ISO format)
- Polymarket UI: ET (Eastern Time)
- Frontend display: dual format `Local · ET`
- Calendar grouping: **local timezone** (pakai `localDateKey()`)
- Window timestamps: UTC seconds in slug

### 5. Binance (Primary Data Source)
- Binance is PRIMARY untuk price + klines (better volume accuracy)
- Fallback: CoinGecko → CryptoCompare
- **Geo-block di Indonesia** — pakai VPN SG
- Latency indicator di info strip frontend

### 6. Auto-claim Real Mode
- `redeem_winning_positions()` self-gated on `MODE == "real"`
- Adaptive polling: 300s (critical), 15s (any expired pos), 60s (normal)
- Max 3 retry → `REDEEM_CRITICAL` log (needs manual review via Polymarket UI)
- Capital di-credit via `close_position(won=True)` even kalau redeem fail (track internally)

### 7. Real Mode Safety
- Bot starts **PAUSED** (`S.running = False`) at REAL mode startup
- User harus klik RUN di UI
- Mode switch ke REAL ditolak kalau no credentials
- Mode switch FROM REAL ditolak kalau ada open positions
- Pre-flight validator wajib lulus dulu

## Common Gotchas

1. **`/tmp/polypox-{BOT_ID}` HILANG saat reboot** — moved to `bot/data/{BOT_ID}/` (persistent)
2. **History limit di WS init** — sebelumnya 40, sekarang 300 (avoid total_pnl ≠ calendar sum)
3. **HistoryCard color** — pakai WIN/LOSS color (status), bukan UP/DOWN (side), supaya konsisten
4. **stdout buffering Python** — pakai `PYTHONUNBUFFERED=1` + `-u` flag supaya log realtime ke file
5. **Vite localhost vs 127.0.0.1** — macOS resolve `localhost` ke IPv6, run.sh check both
6. **USDC allowance != balance** — punya balance tapi belum approve → trade akan gagal
7. **CLOB markets API** — wajib pakai `conditionId` (hex), bukan Gamma integer id
